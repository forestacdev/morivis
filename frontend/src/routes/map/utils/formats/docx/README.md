# Word

`.docx` の本文（表のセルを含む）にあるDrawingML図形・グループ・テキストボックス・埋め込みラスター画像を読み込む。
同じ段落・同じ配置基準の浮動図形を1つの図面として扱い、行内画像は個別に選択する。
Wordのページ組版を再実装せず、異なる段落のローカル座標を混ぜない。

`AlternateContent` はDrawingMLの分岐だけを採用し、VMLの代替表現を二重に読み込まない。
浮動図形の座標・大きさ・重なり順、テキストボックス内の直接指定された文字書式を共通描画形式に変換する。
外部画像にはアクセスしない。

Excelと共通のSVG描画・PNG化を経て、四隅の位置合わせから画像レイヤーとして登録する。
登録後のPNGと位置情報はレイヤーメニューからダウンロードできる。

本文・表・ヘッダー・フッター・ページ組版、Wordの段落スタイル継承、VMLのみの図形は対象外。
中央揃えなど位置を確定できない図形や、EMF/WMF等の未対応画像は省略して画面に通知する。
模様・グラデーション塗り、線端の矢印などの制限はExcelの共通描画処理と同じ。
フォントは閲覧端末で利用できるものを使う。旧バイナリ形式 `.doc` は対象外。

回帰テストは `office-drawing/__fixtures__/documents.ts` の架空データだけを使用する。

「オートシェイプの線」を選ぶと、図形の輪郭を個別のLineStringとして位置合わせし、1pxの線レイヤーとして登録する。
図形名とテキストは属性に保存し、グループ内の座標変換も適用する。塗り・画像は線には含めない。
