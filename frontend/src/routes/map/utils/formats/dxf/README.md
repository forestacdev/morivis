# DXF

`DxfForm.svelte` で単位・読み込み方式・レイヤーを選択する。`$INSUNITS` が未指定・0の場合は単位選択を必須にする。
XYZと長さ属性をメートルへ換算してから後続処理へ渡す。手動の単位指定はヘッダー指定を置き換える。

## 3D面の読み込み

ポリフェイスメッシュや標高を持つポリゴンで「3Dモデル」を選ぶと、`mesh.worker.ts` で色付きGLBへ変換し、
既存の `MeshModelForm.svelte` に渡す。配置後は `createGlbEntry()` のmesh entryをthree.jsで描画する。
座標はモデル中心XY・最下点Zを原点としたメートル座標へ移し、DXFのZ-upをGLBのY-upへ変換する。
配置位置は3Dモデルの配置フォームで指定する。元の座標原点はGLBのextrasに記録するが、地理座標として自動配置はしない。

- ポリフェイスの面レコードは頂点番号で解決し、ダミー座標を形状へ混ぜない。
- `3DFACE` は `face.ts` のhandlerで頂点番号別に読む。dxf-parser 1.1.2標準handlerで、座標の後に辺フラグなどがあると最後の頂点が欠落する問題を回避する。
- 垂直面も含めて面ごとの投影平面で三角形分割する。穴と各頂点の高さを保持する。
- POLYLINEは元のエンティティごとに別のMeshとして保持する。同じレイヤーでも結合しない。
- 単独の3DFACEなどはレイヤー別にまとめる。部材の意味的な区分や失われたコンポーネント階層は推定しない。
- 各Meshに名前・元レイヤー・エンティティ番号を付け、部品ごとの原点とモデル内の配置関係を保持する。
- DXFの色はLinear-sRGBの頂点色として保持し、頂点色用マテリアルはモデル内で共有する。
- 重複頂点で面にならないものや面積ゼロの三角形は除外する。
- 変換中のキャンセル・入力変更では古い結果を配置画面へ渡さない。

点・線・通常の2Dポリゴンは、既存の座標系選択とGeoJSON登録経路を使う。
CityGMLなど、他形式の描画経路には影響しない。

## 2Dでの読み込み

3Dの面でも、フォームで2D表示を選べる。`planar.ts` でXY平面へ投影してから座標系選択・位置合わせへ渡す。

- **2Dポリゴン**: 面と穴を保持し、投影後の面積がゼロになる垂直面を除く。重なる面の統合や建物外形への加工は行わない。
- **2Dライン（面の輪郭）**: 各面・穴の辺を線分にする。壁の位置も残し、同一フィーチャー内の重複辺と長さゼロの辺を除く。
- 元が点・線の場合も2Dを選べる。高さを除き、XYが重複する線の頂点や長さゼロの線を除く。
- 色・レイヤーなどの属性を保持する。登録時は `allow3d: false` で通常のGeoJSON vector entryを作る。

三角形分割はthree.jsの [ShapeUtils](https://threejs.org/docs/pages/ShapeUtils.html)、
GLB出力は [GLTFExporter](https://threejs.org/docs/pages/GLTFExporter.html) を使う。
