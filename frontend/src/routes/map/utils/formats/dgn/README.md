# MicroStation DGN V7

`.dgn`を専用フォームへ渡し、Worker内のTypeScriptパーサーで読む。
DGN読み込みの実行時にはGDAL・WASM・仮想ファイルシステムを使用しない。
ファイル選択・ドロップ・ZIP内の単一図面に対応する。複数図面や参照ファイルの結合はしない。

## 登録

- `parser.ts`はUint8Arrayを受け取り、FeatureCollectionを直接生成する。バイナリ数値、属性リンク、曲線・複合面の処理を別ファイルへ分ける。
- Workerでファイル世代・要素境界・図形本文を検査する。使用後・中止・入力変更・タイムアウト時はWorkerを終了する。
- V7の2D／3D図面から、線・面・文字位置を2Dへ変換する。高さは除く。3Dモデル生成ではない。
- 図形の種類とレベルを選んで登録する。Level・Type・GraphicGroup・ColorIndex・Weight・Style・Text・EntityNum・MSLinkを保持する。ULinkは種類ごとの生の16bitワード列、解釈できない属性の末尾はUnparsedAttributesとして保持する。
- 色テーブル・塗り色からCAD共通スタイル用のcolorを生成する。線種・線幅・フォント・文字回転の完全な再現は行わない。文字内容はText属性として参照できる。
- 座標はDGNのマスター単位。内部整数座標・sub-UOR補正値に単位倍率とグローバル原点を適用する。単位名からの自動メートル換算や座標系推定はしない。
- `convert.ts`は既存の座標系辞書・proj4・必要な測地変換グリッドを使用する。選択したCRSと入力座標の単位が一致している必要がある。
- 座標系不明なら共通の位置合わせへ渡す。フォームには次元・主単位・未対応要素数・B-splineの近似件数を表示する。

## 対応範囲と制限

- 線（3）、折れ線（4）、面（6）、曲線（11）、複合線（12）、複合面（14）、楕円（15）、円弧（16）、文字位置（17）、B-spline制御点列（21）を読み取る。
- 曲線はDGNLibと同じXYのAkima補間、円弧・楕円はおおむね5度刻みの折れ線にする。3D円弧・楕円はquaternion回転後のXY投影を使う。B-splineは制御点を結ぶ折れ線であり、曲線そのものの再現ではない。
- 複合線はMultiLineString。複合面は接続する辺をリングへ組み立て、包含関係で外周・穴を分ける。離れた端点を自動接続しない。開いた境界や構造の矛盾はエラーにする。
- セル／テキストノードは後続の子図形を個別に読む。セル階層・共有セルの展開、ソリッド、外部参照、ハッチングは再現しない。
- 文字コードはファイル内で特定できないためUTF-8として読む。その他の文字コード・MicroStation独自の多バイト文字の再現は未対応。
- V8は未対応としてV7 DGNまたはDXFへの変換を案内する。
- 入力64 MiB、出力JSON換算128 MiB、50万地物、500万頂点、120秒。上限の定義元は`definition.ts`。地物と座標の生成中に検査し、出力容量は1地物ずつ計算する。メモリ使用量そのものの上限ではない。
- 複合図形の再帰は20段まで。破損した対応要素は部分成功にせず処理を止める。未対応要素は種別・件数を返す。制御レコードは除外数に含めない。

## 検証

`__fixtures__/generate.mjs`は外部の`ogr2ogr` CLIとそのseedから架空の2D／3D図面を再生成する任意の開発用スクリプト。アプリ・テスト・ビルドにはGDALは不要。
`__fixtures__/builders.ts`と`generate-extra.ts`は、曲線・円弧・複合図形・座標補正・原点を含む架空のISFFレコードを生成する。
テストではGDAL 3.8.4で取得してGit管理した`*.expected.json`と座標・図形を照合する。再生成した期待値は差分を確認して更新する。
実データは回帰テストへ組み込まない。
