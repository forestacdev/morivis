# FIT

`.fit` のGPS記録をWGS84のGeoJSONへ変換し、通常のvector entryとして登録する。
解析にはMITライセンスの [fit-file-parser](https://github.com/jimmykane/fit-parser) を使用する。

- 軌跡（線）、計測点、コースポイントから読み込み対象を選択する。
- 計測点には時刻、標高、累積距離、心拍、ケイデンス、パワー、速度、気温、GPS精度を保存する。入力にない値は補完しない。
- 標高・距離はm、速度はm/s、時刻はUTC。enhanced altitude/speedがあれば優先する。
- 時刻付きの地物には既存の時系列フィルターを設定する。
- GPS欠落・不正座標や停止イベント、セッション終了、時刻の逆転で線を分割する。単独点は計測点として利用できる。
- 座標系フォームは不要。位置情報のない屋内記録などは理由を表示して登録しない。
- 専用Workerとスクリーンガードを使用。64 MiBまで、解析タイムアウトは120秒。キャンセル時はWorkerを終了する。
- ヘッダー・CRC・データ境界を検証する。破損データの部分取り込みは行わない。

ワークアウト指示、健康情報のみのファイル、メーカー独自の計測フィールドの表示には対応しない。
ラップやセッションの集計値は属性へ展開しない。軌跡の線の時刻は区間開始時刻。

`__fixtures__/generate.mjs` は架空データだけを使う独立したバイナリ生成コード。
位置の欠落、停止イベント、12/14バイトヘッダー、big endian、圧縮時刻、未知developer fieldを含む。
