# AISログ

NMEAのVDM/VDOセンテンスに保存されたAISログを、WGS84のGeoJSONへ変換する。船舶ごとの位置報告と航跡を通常のvector entryとして登録する。

## 対応範囲

- `.ais`、内容判定した `.nmea`・`.nme`・`.log`・`.txt`。ZIP展開後も同じ判定を使う。複数ファイルは結合せず選択して登録する。
- `!AIVDM`・`!AIVDO`と他のトーカーIDのVDM/VDO。GNSS文と混在する場合はAISだけを表示する。
- 位置報告はタイプ1・2・3（Class A）と18（Class B）。タイプ5、24A/Bの船名・呼出符号・船種などを同じMMSIの位置報告へ付加する。静的情報はファイル内で最後に得られた有効な項目を使用する。
- タイプ19・27など上記以外は未対応件数に数えて表示対象から除く。CSV・JSONのAIS配信データやリアルタイム接続は対象外。

復号にはMITライセンスの [ais-stream-decoder](https://github.com/mjaros/ais-decoder) 2.1.2を使う。Node.js stream入口を避け、同梱のbitfieldとメッセージ復号モジュールをWorkerから読み込むため、バージョンを固定している。NMEA外枠の検査・分割文の組み立て・時刻とGeoJSONへの変換はmorivis側で行う。ライブラリの旋回率変換は使用しない。

## 分割文と検証

センテンスとタグブロックのチェックサム、断片番号、ペイロード長、埋め草ビットを検査する。分割文は受信局・トーカー・チャネル・連番・タグのグループIDで区別する。IDありは順不同、IDなしは同じ識別キー内で断片番号順に揃った場合だけ復号する。重複や不一致、1000行を超えて離れた断片は組み直し、未完了として数える。未完了グループは最大1024個まで保持する。

チェックサム不一致や短いペイロード、位置不明値（経度181度・緯度91度）、範囲外座標は除外件数を表示する。船舶が区別できない破損文の前後、同じ船の無効位置の前後は航跡をつながない。

## 時刻と航跡

- NMEAタグブロックの `c:` のUnix秒（小数可）と13桁Unixミリ秒、`s:` の受信局、`g:` の断片グループに対応する。
- 行頭のISO 8601日時は `2024-01-02T00:00:00Z !AIVDM,...` のようにUTCまたはオフセットが明示された場合に受信時刻として扱う。タグの時刻を優先する。
- AIS内のUTC秒だけでは日付や時分を補わない。日時のないログは記録順に表示し、現在日時・ファイル更新日時は補わない。
- 日時があるポイントは時刻軸を作る。初期表示は全点とし、ユーザーが既存の時刻フィルターを有効化できる。受信時刻は船上で測位した日時を保証するものではない。
- 航跡はMMSIごとに記録順で作り、受信局の変更、日時の有無の変化、日時逆転、30分超の間隔、日付変更線で分割する。2点未満の区間はラインにせずポイントに残す。航跡は開始・終了時刻を属性に保持し、全期間を表示する。

位置属性にMMSI、船名、AIS種別、対地速度（ノット）、対地針路、船首方位、航海状態、受信時刻などを保持する。取得できない速度・方位・UTC秒の属性は省略する。

## 制限と検証

入力32 MiB、25万位置報告、2万船舶、1行2048文字、Worker120秒を上限とする。キャンセル・入力変更・タイムアウト時はWorkerを終了する。

`__fixtures__/encode.ts` は単純な任意座標と架空の船名・識別番号だけでテスト入力を生成する。`test-vessels.ais` は時刻付き2船舶、`test-untimed.ais` は日時のない航跡。実際の受信ログをfixtureへコピーしない。
