# Minecraft Java Edition MCA

地形リージョンの `.mca` をブラウザ内のWorkerで読み、頂点色付きGLBに変換する。
生成したファイルは既存の `MeshModelForm` → `MeshEntry` → three.js のフローに渡す。
ワールド座標は緯度経度に変換せず、ローカルモデルとして位置・向き・縮尺を指定する。

## 対応範囲

- Java版1.13以降のブロックパレット形式（`Level.Sections` / `sections`）
- gzip・zlib・非圧縮のチャンク
- 1.13〜1.15の連続ビット列と1.16以降のlong境界パディング
- 負のチャンク座標・負のセクション高さ
- 1回につき地形MCAを1ファイル。リージョン内のX/Zチャンク範囲（0〜31、両端を含む）を指定可能

1.12以前の数値ブロックID、LZ4圧縮、外部 `.mcc` はエラーで案内する。
`entities` / `poi` 内の同じ拡張子のファイルは地形として扱わない。
対応する保存構造を架空fixtureで検証しており、すべてのMinecraftリリースの実ワールドでの動作を保証するものではない。

## 表示

空気以外は不透明の立方体として近似する。色はブロック名に基づく代表色で、未知の名前にも固定色を割り当てる。
テクスチャ、バイオームの色、照明値、ブロックの向き・階段などの形状、水やガラスの透過、エンティティは再現しない。

隣接セクション・チャンクを含めて内部面を除外し、同一ブロックの面を矩形にまとめる。
選択範囲の境界には断面を作る。GLBの座標単位は1ブロックだが、モデル登録時に既存の初期表示倍率が適用される。
ブロック編集・ワールドの書き戻しには対応しない。

## ファイルと上限

- `nbt.ts`: big-endian NBT、長さ・深さ・ノード数を検証
- `region.ts`: MCAヘッダー検証、チャンク展開、共通パレットへの正規化
- `mesh.ts`: 内部面除去・面結合
- `glb.ts`: Workerで動くGLB 2.0書き出し
- `analyze.ts` / `worker.ts`: 進捗通知とWorker終了によるキャンセル

入力256 MiB、展開後NBT32 MiB/チャンク、32,768の非空セクション、結合後50万面が上限。
重い入力で上限に達した場合は部分的なモデルを登録せず、範囲を狭めるよう案内する。

仕様確認に利用した実装: [PrismarineJS Anvil provider](https://github.com/PrismarineJS/prismarine-provider-anvil)。
Node用ファイルI/Oには依存せず、NBT・region読み取りとメッシュ生成は独立した関数としてテストする。
