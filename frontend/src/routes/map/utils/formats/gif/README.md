# GIF

GIFをドロップすると、ブラウザ内の専用WorkerでMP4（H.264）へ変換し、動画と共通の位置合わせへ進む。位置合わせ後は既存の `RasterVideoEntry` として無音・ループ再生する。変換用のFFmpegとWASMはGIFの使用時に同じ配信元から読み込む。ファイルの外部送信は行わない。

透明部分は白背景に合成する。奇数の幅・高さは右端・下端に白い1ピクセルを足す。GIF内のフレーム間隔とdisposalの合成はFFmpegで扱い、GIFのループ指定は無視して1周分を変換する。地図上では動画の既存仕様に合わせて繰り返す。

入力は32 MiB、縦横4096ピクセル、画面の画素数×フレーム数は128 Mi画素まで。構造と処理量を復号前に検査する。読み込みと変換は合計120秒までとし、成功・失敗・キャンセル・タイムアウト時にWorkerを終了してメモリを解放する。

`__fixtures__/test-animation.gif` は `node frontend/src/routes/map/utils/formats/gif/__fixtures__/generate.mjs` で生成した架空の図形。65×49ピクセル、透明背景、赤・青・緑の3フレーム、表示時間200・500・300 ms、無限ループを持つ。
