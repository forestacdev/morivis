# GCD

GeoCloud / GeoConic GCDのうち、先頭が`38 14`の2D座標列を読み込む。
公開仕様ではなく手元で確認できた構造に限定した実装。全バージョンの互換性は保証しない。

- `index.ts`: ArrayBuffer → 投影座標のGeoJSON境界線とEPSG。
- `worker.ts` / `analyze.ts`: Workerで解析後、既存の座標変換WorkerでWGS84へ変換。複数ファイルは変換後に結合する。
- `GcdForm.svelte`: GeoJSONのLineString entryへ登録。標準のentry → MapLibre spec → runtimeの表示経路を使う。
- `dialog-registry.ts`: BaseDialog / DialogRendererからフォームを遅延読込する。

## 対応範囲

- 長さ付きレコード、符号なしLEB128整数、UTF-16コード単位ごとの可変長整数文字列。
- EPSG付きヘッダー、2Dの符号付き差分座標（モード`45`）、単一・複数パート（型4・12）。
- 文字列属性（型3）と文書参照文字列（型9）。参照先のファイルは取得しない。
- 閉じた図形も境界線として保持する。塗り、独自記号、曲線補間、描画順の再現は対象外。
- メタ情報・記号定義・スタイルのセクションはレコード長で分離し、表示スタイルには適用しない。

ヘッダーの座標範囲と復元後の範囲を照合する。未知のバージョン・図形型・座標符号化・属性型・座標変換はエラーとし、ファイルの一部だけを登録しない。
EPSGが未登録の場合も位置を推測せずエラーにする。
上限は合計128 MB・32ファイル、1ファイル20万図形・200万頂点。

実データはfixtureへ含めない。合成データで座標復元、属性、複数パート、破損・未対応形式を検証する。
