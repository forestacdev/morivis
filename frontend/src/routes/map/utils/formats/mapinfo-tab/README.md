# MapInfo TAB

Native TAB（TAB・DAT・MAP・ID、任意のIND）と、属性がDBFのベクターTABを読み込む。
一式を同時にドロップするか、ZIP・フォルダで読み込む。同じフォルダ・名前だけを対応付ける。
複数のTABがある場合は表を選択する。不足していたDAT・MAP・IDは開いたフォームへ追加ドロップできる。

## 処理

- 専用Worker内のTypeScriptパーサーでTABの属性定義、DAT/DBFの属性、IDの行参照、MAPの図形を読む。GDAL・WASM・仮想ファイルシステムは使用しない。
- 点・線・面・複数点・複合図形、矩形・角丸矩形・楕円・円弧・文字の位置を扱う。圧縮／非圧縮座標とV300/V450/V650/V800の図形レコードに対応する。曲線は線分化する。
- 文字コードはTABのCharsetに従う。WindowsJapaneseはShift_JISとして読む。未対応の文字コード・図形型、壊れた参照、循環する座標ブロックはエラーにする。
- 埋め込みCRSはMAPの投影パラメーター、楕円体、測地変換、単位からproj4定義へ変換する。WGS84、Web Mercator、TM、LCC、Albersなどを扱う。
- NonEarth、アフィン付きCRS、未対応の投影・楕円体、proj4での変換失敗は元座標を保持して座標系選択へ渡す。明示した座標系で変換できない場合はエラーにする。
- `MapInfoResult.sourceCrs`は読み取れた埋め込みCRSのproj4定義またはEPSGコード。不明な場合は空文字。WKTは生成しない。
- 図形の種類が1つなら自動でエントリー登録へ進む。混在する場合はポイント・ライン・ポリゴンを選ぶ。
- `createGeoJsonEntry()`で通常のベクターentryを生成する。描画は既存のentry → spec → MapLibre経路、手動位置合わせは既存のGeoRefを使う。
- Workerは処理完了・エラー・キャンセル・120秒のタイムアウトで終了する。ファイルは外部へ送信しない。

## 制限

- 一式256 MiB、TABヘッダー1 MiB、50万行、500万頂点まで。点数は座標配列を作る前にも検査する。
- ラスターTAB、結合表・シームレス表、NativeXは未対応。未対応の投影は座標系を選択する。
- 外部属性ファイルの明示参照は同じフォルダ内のみ。
- 元の線種・記号・フォント・ラベル配置は再現せず、morivisの標準スタイルを使う。文字オブジェクトは位置を点として扱う。
- 図形のない行は表示から除外し、数を表示する。削除済み属性行は読み飛ばす。属性だけの表は登録しない。
- 出力は2D。複数種類の図形を登録する場合は、同じTABを再度読み込んで種類を選ぶ。
- LargeIntがJavaScriptの安全な整数範囲を超える場合は、桁を失わないよう文字列として保持する。

## 検証データ

`__fixtures__/`は任意の座標と架空属性だけで作成した入力と、GDAL 3.8.4で取得した固定期待値。
地理座標、投影座標、日本語、NonEarth、穴のある複数面、複数ブロック、日付・時刻・論理値を含む。
`builders.ts`では圧縮／非圧縮の各図形とV450/V800、欠損・不正参照を検証するためのバイナリを組み立てる。
テストはTypeScriptパーサーとGit管理された期待値だけを使い、GDALのインストールを必要としない。

`generate.mjs`は外部`ogr2ogr` CLIによる任意の再生成用スクリプト。アプリ・テスト・ビルドからは実行しない。
期待値を再生成した場合は使用したCLIのバージョンと差分を確認する。
