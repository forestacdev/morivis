# Jw_cad / JWC

DOS版 `.jwc` → Workerでバイナリ解析 → JWWと共通の図形変換 → 実寸mの2D GeoJSON → 座標系指定または位置合わせ → `MorivisVectorEntry`。

- 固定長ヘッダー2389バイト（整数縮尺）と2421バイト（浮動小数点縮尺）の2種類に対応。その他の世代やレイアウトはエラーにする。
- 線・円弧・楕円はライン、実点・文字はポイント。仮点は除外する。
- 紙面座標を用紙サイズとグループ縮尺から実寸mへ換算する。地図座標とは自動判定しない。
- Shift-JIS文字列、グループ・レイヤー名、表示状態、ペン番号を保持する。
- RGBパレットはこのレイアウトから復元できないため、ペン番号に既定色を割り当て、その旨をフォームに表示する。元図面の色の完全再現ではない。
- 文字プール参照、レコード数、ファイル長、有限座標を検証し、破損した入力はエラーにする。

参照: [monozukuri-ai/ezjww](https://github.com/monozukuri-ai/ezjww) の `ezjww-core/src/jwc`。MITライセンスの通知を [LICENSE.ezjww](LICENSE.ezjww) に同梱している。

テスト入力は `__fixtures__/builder.ts` で生成する架空の図面のみを使う。
