# ローカルラスタータイル

`{z}/{x}/{y}.png` / `.jpg` / `.jpeg` / `.webp` のフォルダ、または階層を保持したZIPを受け取る。
タイル画像は256×256または512×512ピクセル。登録時に1枚だけ開いてサイズを確認する。

`tilejson.json` があれば名前・範囲・XYZ/TMSの方式を参照する。
ない場合はXYZを既定とし、フォームからTMSへ切り替えられる。
画像だけを階層から取り出すと位置を特定できないため、通常の画像取り込みに渡す。

`MorivisRasterEntry`（format: `image`）へ正規化し、既存のsource/layer生成を使う。
`local-raster://` が要求された画像だけを読み、欠けた座標には透明PNGを返す。
MVTと共有するレジストリでコピー・削除時の参照を管理する。
通常の画像タイルとして扱うため、DEMの標高デコードは行わない。

ZIPは既存の処理で全体を展開する。大容量ではフォルダを直接ドロップする。
ページ再読み込み後はフォルダを再度ドロップする必要がある。
