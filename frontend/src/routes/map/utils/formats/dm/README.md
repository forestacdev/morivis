# DM読み込み

DMを平面直角座標のGeoJSONへ変換し、座標系の確認後に通常のベクターentryへ登録する。

- Shift-JISのバイト位置で固定長フィールドを読み、文字列フィールドを個別に復号する。
- F/D2/D3/L形式とE1〜E7形式を扱う。IレコードとE形式の併存にも対応する。
- 系番号の候補は、同じディレクトリのDMI、DM内のIレコード、標準的な図郭番号の順で取得する。
- DMIはDMと一緒に選択・ドロップする。ZIPも同じ導線を通す。複数のDMがある場合はフォームで対象を選ぶ。
- 図郭番号は5000・2500・1000・500・250レベルの形式を確認してから系番号を推定する。任意番号から先頭数字だけを拾わない。
- 同じ優先順位に異なる系番号がある場合は警告を表示する。不明な系番号を2系・9系へ置き換えない。
- 系番号だけでは測地系を確定できないため、パーサーの`epsgCode`はnull。Zone画面にはJGD2011の候補を渡し、ユーザーが位置を確認して確定する。
- 建物分類（30xx）の面で図形区分31を中庭とする。同一図郭内の外形（図形区分0）に完全に含まれる場合だけ内周へ変換し、中庭の独立面を除く。複数の外形に含まれる場合は面積が最小のものを選ぶ。
- 外周への接触・交差、既存の穴との重なり、対応する建物がない中庭は元の形状を残す。

QML・QLRとGeoPackage出力は対象外。E8属性、グリッド・TIN、複数行注記の完全な再現は未対応。

仕様の参照先:

- [数値地形図データファイル仕様（林野庁掲載）](https://www.rinya.maff.go.jp/kanto/apply/publicsale/kanri/pdf/furoku8-1.pdf): インデックス、図郭、要素レコードのバイト配置、図形区分31。
- [大縮尺数値地形図データ標準製品仕様書（国土地理院）](https://www.gsi.go.jp/common/000259074.pdf): DM図郭番号の桁数・形式。

回帰テストは`__fixtures__/records.ts`で生成する架空レコードを使用する。
