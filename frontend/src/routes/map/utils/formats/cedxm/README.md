# CEDXM

`CADIF` をルートに持つCEDXMのXMLをWorkerで解析する。UTF-8とShift-JISに対応し、mmをmに換算する。
ファイルドロップ後の `CedxmForm.svelte` で階・部材種別と2D/3Dを選ぶ。

- 2D: 柱・部屋・屋根・階段は平面ポリゴン、横架材・補助部材・壁・開口・外壁線はライン。図形種別を選択して座標系指定または位置合わせを行い、GeoJSONのベクターエントリーへ登録する。
- 3D: 柱・横架材・補助部材・壁は寸法から作る簡易メッシュ、部屋は床面、開口と屋根は面。部材ごとにオブジェクトを分けてGLBに変換し、既存モデル配置フォームから `MeshEntry` へ登録する。
- 元の部材ID、種別、階、寸法などの属性を保持する。色は部材種別ごとの既定色。
- 解析ロジックは描画オブジェクトを持たず、`mesh.ts` でのみthree.jsのオブジェクトを生成する。

## 簡易モデルの範囲

横架材・補助部材の始終点を中心線、寸法1/2を矩形断面の幅/高さとして扱う。断面回転や継手・仕口は再現しない。
屋根は基準線の左側を上り勾配として面を作る。屋根厚、軒先補正、詳細な納まりは再現しない。
壁の開口は別の面で表し、壁から穴を切り抜かない。階段は2Dの外形のみで、段形状を生成しない。
これらの制限は取り込みフォームでも表示する。施工・加工用モデルの再現を目的としない。

形式の背景: [CEDXM公式サイト](https://www.cedxm.com/)。現在のパーサーは対応する部材要素を明示して実装し、未知の部材には読み飛ばしの警告を出す。

回帰テストは `__fixtures__/test-building.xml` の架空の建物を使用する。
