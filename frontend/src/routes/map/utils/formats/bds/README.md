# SIS BDS

SISのBDSを2D GeoJSONへ変換する限定対応。公式のバイナリ仕様書に基づく実装ではなく、確認できた版41の構造のみを読む。

## 読み込み

- `index.ts`: 純粋なArrayBufferパーサー。末尾MARKから検証マーカーを逆順に復元し、各レコードの境界・クラス・版を照合する。
- `worker.ts` / `analyze.ts`: Workerで解析し、ヘッダーの投影パラメーターを既存の座標変換Workerへ渡してWGS84へ変換する。
- `BdsForm.svelte`: ドロップ・選択後に自動解析する。変換後は既存のGeoJSONフォームへ渡し、図形種別の選択、MorivisLayerEntryの作成、プレビューを共通化する。
- 複数ファイルは変換後に結合し、ファイル名属性を追加する。空ファイルは通知し、全件空なら登録しない。未対応・破損ファイルが混じる場合は一括処理を中止する。

## 対応範囲

- 直線列、複数の境界線、グループの子図形、文字注記の位置。
- 文字列・整数・実数の属性。グループの属性は子へ引き継ぐ。同名の場合は子の値を優先する。
- 円弧・ベジェ区間は端点間の直線へ置き換える。制御点を図形の頂点とはみなさない。
- 閉じた図形もLineString / MultiLineStringへ変換する。穴・外周の意味を推測して塗りを付けない。
- 文字注記はPointと文字属性へ変換する。文字の回転・大きさ・フォントは再現しない。
- 部品定義は構造を検証するが、配置された地物としては登録しない。未知の配置変換・図形型・クラス版は拒否する。
- 読み取り対象の投影法は、GRS80、測地系値6612、追加変換なしの横メルカトル。投影原点・縮尺・オフセットはファイルから読む。その他の測地系は未対応。
- 元のスタイル、画像、3D表示は対象外。Zは読み飛ばさず数値として検証してから2D化する。

入力上限は合計32 MB・32ファイル。パーサーは頂点数・アイテム数・レコード数・再帰深度も制限する。
テストは架空の生成fixtureのみを使用し、実サンプルを参照しない。
