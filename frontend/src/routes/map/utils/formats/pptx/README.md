# PowerPoint図面

`.pptx` のスライド内にあるDrawingML図形・コネクタ・グループ・テキスト・埋め込みラスター画像を読み込む。
スライド順は `presentation.xml` の参照順を使い、テーマはスライドからレイアウト・マスターの参照をたどる。
外部画像にはアクセスしない。

図形の範囲で切り出し、Excelと共通のSVG描画・PNG化を経て、四隅の位置合わせへ渡す。
登録後は `imageCorners` を持つ画像レイヤーとなり、レイヤーメニューからPNGと位置情報をダウンロードできる。

スライドの背景・マスター上の図形・継承されたプレースホルダー・表・グラフ・SmartArtは再現しない。
EMF/WMF、模様・グラデーション塗り、線端の矢印など、共通描画処理の未対応要素は省略して画面に通知する。
フォントは閲覧端末で利用できるものを使う。旧バイナリ形式 `.ppt` は対象外。

回帰テストは `office-drawing/__fixtures__/documents.ts` の架空データだけを使用する。

「オートシェイプの線」を選ぶと、図形の輪郭を個別のLineStringとして位置合わせし、1pxの線レイヤーとして登録する。
図形名とテキストは属性に保存し、グループ内の座標変換も適用する。塗り・画像は線には含めない。
