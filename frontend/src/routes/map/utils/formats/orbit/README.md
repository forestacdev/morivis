# TLE / OMM

`satellite.js` 6.0.2のTLE・OMMデコーダーとSGP4/SDP4計算を専用Workerで実行し、衛星の地上位置・地上軌跡をWGS84のGeoJSONへ変換する。通常のvector entryとして登録し、ポイントの時刻切替には既存のtemporal filterを使う。軌道計算や描画オブジェクトをentryに保持しない。7系のWASM用Workerは現行Viteのビルド対象と互換性がないため、6系を使用する。

## 入力

- TLEの2行形式、名称を添えた3行形式、`0`接頭辞付き名称。複数衛星、BOM・CRLFに対応する。第1行・第2行はチェックサム付き69文字。衛星番号の一致、チェックサム、数値と日時の範囲を検査する。
- OMM JSONの単一オブジェクト・配列。CelesTrakなどの省略メタデータ形式とバージョン3に対応する。数値・数値文字列を扱う。明示されたCENTER_NAME / REF_FRAME / TIME_SYSTEM / MEAN_ELEMENT_THEORYはEARTH / TEME / UTC / SGP4に限定する。XML・KVN・CSV形式は対象外。
- `.tle`・`.omm`、内容を判定した`.txt`・`.json`。ZIP展開後も同じ判定を使う。複数ファイルは文書を選択して個別に登録する。
- 同じ衛星番号の重複はエラーにし、異なる時期の軌道要素を勝手に結合・選択しない。

## フォームと計算

ファイルを選択すると衛星情報を自動解析する。テキスト入力では最初の「登録」で情報と計算期間を表示し、期間を確認・変更して同じ「登録」で計算する。追加の解析ボタンは設けない。

開始・終了時刻はUTC、計算間隔は秒。既定は入力内の最新の基準時刻から2時間、60秒間隔で、現在日時を暗黙に補わない。終了時刻は間隔で割り切れない場合も含める。軌道要素の基準時刻から14日を超える計算は、精度低下の可能性をフォームで通知する。この閾値以内の精度を保証するものではない。

SGP4のTEME位置をsatellite.jsのGMST・経緯度変換で地上位置にする。CZMLのICRF変換とは別の座標系であり、IAU2006 XYS表は使用しない。位置は2Dで、衛星の楕円体高はメートルの属性として保持する。高度付き3D軌道や衛星モデル、地上からの可視範囲は対象外。

ポイントは衛星番号・名称・基準時刻・計算時刻・高度を持ち、最初の時刻だけを表示して登録する。地上軌跡は日付変更線で分割し、区間の開始・終了時刻を保持する。軌道計算に失敗した場合は、衛星と時刻を示して登録を止める。

入力8 MiB、1000衛星、計算期間7日以内、間隔1〜86400秒の整数、衛星数×時刻数20万点、Worker120秒が上限。取消・入力変更・タイムアウトではWorkerを終了し、古い結果を登録しない。
