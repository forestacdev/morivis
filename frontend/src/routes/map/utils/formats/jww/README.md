# Jw_cad / JWW

`.jww` → WorkerでMFC CArchiveを解析 → ローカルの2D GeoJSON → 座標系指定または位置合わせ → `MorivisVectorEntry` → MapLibre。
旧DOS形式の `.jwc`、図形ファイル `.jws` は対象外。

## 取り込み

- 内部データバージョン200～700。ファイルバージョンでヘッダー・図形のフィールド構成を切り替える。クラスのschema番号は別物として扱う。
- 線・円弧・楕円・寸法線はライン。実点・文字はポイント。通常のソリッド・扇形・弓形・円環はポリゴン。円周ソリッドはライン。
- ブロックは移動・拡大・回転を再帰適用して展開し、ブロック名と参照番号を属性に残す。循環・欠落参照はエラーにする。
- 座標は紙面のmm。最上位図形のレイヤーグループの縮尺分母を掛け、1000で割って実寸mにする。ブロック内部に縮尺を重複適用しない。
- グループ/レイヤー名、表示状態、ペン番号、線種、COLORREF（通常色・SXF拡張色・ソリッド任意色）を保持。非表示レイヤーはフォームで初期選択しない。
- 小さいローカル座標でも経緯度と自動判定しない。利用者が位置を指定する。選択した図形種別とレイヤーを1つのGeoJSONエントリーに登録する。
- 色と文字ラベルのスタイルは座標変換・位置合わせの両経路で保持する。
- 予約位置に置かれた既知の印刷・表示設定レコードを図形から除外する。通常の位置にある同名の文字列は注記として残す。

## 表現の範囲

円弧は最大2度ごとに折れ線化する。線幅・線種、文字の元フォント・サイズ・回転は属性として保持するが、CADの印刷表現は再現しない。
矢印・点マーカーはポイントに置き換える。仮点、貼り付け画像、外側円弧ソリッド等の未対応の円ソリッドは除外理由をフォームに表示する。
未知クラス・未対応バージョン・破損した参照や長さは、位置を推測して読み飛ばさずエラーにする。
2.5Dの設定は3Dモデルへ変換しない。
