# 地形図図郭の前処理

補助レイヤーの「地形図図郭」は、既存の `geojson://` プロトコルを使用する。
`transform=topographic-sheets` を付け、図郭固有の取得と図形変換だけを追加する。
専用プロトコル・専用Workerは作らず、共通の `protocol_geojson.worker.ts` でタイル化する。

[地理院地図の GSI.TGrid](https://github.com/gsi-cyberjapan/gsimaps/blob/45bf3d3e5af4a92d4592f71e6d6d251b50f72014/js/gsimaps.js#L35178) の配信先と切替ズームを参照している。

| 表示ズーム | 図郭 | GeoJSON配信ズーム |
| --- | --- | --- |
| 5〜8 | 20万分1 | 5〜8 |
| 9〜10 | 5万分1 | 9〜10 |
| 11以上 | 2万5千分1 | 8 |

20万・5万分1はPolygonの外周と中心を線・図名に変換する。
2万5千分1はPointの `図名` と `図郭座標` から枠を復元する。
リモートの `style.js` は実行しない。

表示タイルに対応する配信タイルと隣接8枚を参照し、重複する図郭を除く。
線へ変換してからクリップするため、タイル端に偽の枠線が出ない。
2万5千分1はズーム18まで描画タイルを生成し、配信ズーム8の座標を拡大時にも再計算する。
生成・出力は共通のextentを使い、座標のずれを防ぐ。

取得データは96枚をLRU管理し、同時要求は通信を共有する。
画面移動で中止された要求には応答せず、共有中の通信は継続する。
図郭と通常のGeoJSONタイルがすべて非表示になるか、地図を破棄した際に共通Workerと通信を終了する。
図郭の配信範囲外の404は空データとして扱い、その他の通信エラーは要求元へ返す。

表示状態は `showTopographicSheetsLayer`、スタイルは `createTopographicSheetsStyle()` で管理する。
