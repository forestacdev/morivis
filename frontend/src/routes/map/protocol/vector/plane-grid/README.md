# 平面直角座標グリッド

JGD2011の平面直角座標系第1〜19系を選んで、水色の方眼と座標ラベルを表示する。
PC・モバイルの「平面直角座標」から切り替える。既定はアプリの初期表示地域に合わせた第7系。

Xは北方向、Yは東方向、単位はメートル。proj4の `[easting, northing]` と日本の `[X, Y]` を取り違えない。
測地系はJGD2011固定で、旧日本測地系や座標成果の時点補正は扱わない。
表示範囲は東経122〜156度・北緯18〜46度。系ごとの適用区域でマスクせず、選択した系の座標を表示する。
系の選択欄に適用区域を併記する。

| 地図ズーム | 方眼間隔 |
| ---------- | -------- |
| 0〜8未満   | 100 km   |
| 8〜11未満  | 10 km    |
| 11〜14未満 | 1 km     |
| 14〜16未満 | 500 m    |
| 16〜18未満 | 100 m    |
| 18〜20未満 | 50 m     |
| 20以上     | 10 m     |

5本ごとに線を太くする。ラベルは線に沿って配置し、重なる文字は間引く。
19系すべての原点にポイントと「第N系 原点」ラベルを表示し、選択中の系の原点を大きく表示する。
原点は既存の座標系辞書からGeoJSONを生成し、方眼と同じ表示切り替えに連動する。

## 描画経路

`showPlaneGridLayer` / `planeGridZone` → `createPlaneGridStyle()` → `mapStore.setStyle()`。
タイルURLは `plane_grid://tile/{zone}/{spacing}/{z}/{x}/{y}.pbf`。
系番号をソースIDにも含め、変更前のタイルを再利用しない。
非表示時と地図破棄時にはWorkerと未完了の要求を終了する。

既存の `japan-plane-rectangular.ts` の投影定義を使い、Worker内で方眼を生成する。
要求範囲の辺を分割して投影後の外接矩形を求め、整数の方眼番号から線を作る。
逆投影時は線を分割して曲率を表現し、描画範囲でクリップしてMVTに変換する。
方眼数には上限を設け、低ズームで細かい方眼を大量生成する要求を拒否する。
