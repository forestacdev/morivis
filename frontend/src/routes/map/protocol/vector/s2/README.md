# S2グリッド

補助レイヤーの「S2」で境界線とセルIDを表示する。ズーム0〜23に対応してS2レベルを0〜23へ切り替える。IDはS2標準の16進トークンで表示し、JavaScriptの数値へ変換しない。

`s2_grid://tile/{level}/{z}/{x}/{y}.pbf` をWorkerで生成する。s2jsで6面から表示範囲に交差する子セルだけを探索し、大円の辺をMercator投影後の誤差に応じて細分化する。境界線と中心点をgeojson-vt・vt-pbfでタイル化する。セルの塗りつぶしから線を作らないため、タイル端に偽の境界線が出ない。

表示状態は `showS2Layer`、描画仕様は `createS2Style()` で管理する。非表示時と地図破棄時にプロトコルを解除し、Workerと未完了の要求を終了する。

外部タイル配信やGoogle MapsのAPIキーは使わない。
