# 地域メッシュ補助レイヤー

レイヤーコントロールの「地域メッシュ」で、枠線とメッシュコードを表示する。
通常のアップロードレイヤーとは別の補助表示として `showRegionalMeshLayer` で管理する。

| 地図ズーム | 区画            | およその幅 |
| ---------- | --------------- | ---------- |
| 0〜8未満   | 第1次地域区画   | 80 km      |
| 8〜11未満  | 第2次地域区画   | 10 km      |
| 11〜14未満 | 第3次地域区画   | 1 km       |
| 14〜15未満 | 1/2地域メッシュ | 500 m      |
| 15〜16未満 | 1/4地域メッシュ | 250 m      |
| 16以上     | 1/8地域メッシュ | 125 m      |

コードラベルはズーム4以上で表示し、重なるラベルは間引く。
表示範囲は東経122〜154度・北緯20〜46度。陸域判定は行わず、範囲内の海上にも区画を表示する。

## 描画経路

`showRegionalMeshLayer` → `createRegionalMeshStyle()` → `mapStore.setStyle()`。
ズームに対応するソースだけが使用され、MapLibre のタイル要求に応じて
`regional_mesh://tile/{level}/{z}/{x}/{y}.pbf` を Worker で生成する。
1/8メッシュより拡大した場合はズーム16のタイルを拡大して使う。

区画の計算は `utils/mesh/regional-mesh.ts`、スタイル生成は
`utils/layers/regional-mesh.ts` に分離している。
線と中心点をMVTに変換するため、タイルの切断位置に偽の区画境界は描かれない。
非表示時と地図破棄時にはプロトコルを解除し、Workerと未完了の要求を終了する。

## 参照

- [統計局：地域メッシュの区分方法](https://www.stat.go.jp/data/mesh/m_tuite.htm)
- ユーザー指定の `mesh-jp` の `src/lib/config.ts` と `src/lib/japanmeshMaker.ts`：ズーム切替と生成方式の参考。

コードと座標の計算は整数の区画番号を基に実装し、メッシュ境界における浮動小数点の丸めを補正する。
