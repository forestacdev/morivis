# H3補助レイヤー

H3の区画境界とセルIDをオレンジ色で表示する。PCとモバイルのレイヤーメニューから切り替える。
地域メッシュと同様、カタログのデータレイヤーではなく補助表示として管理する。

`showH3Layer` → `createH3Style()` → `mapStore.setStyle()` の経路で更新する。
`h3_grid://tile/{resolution}/{z}/{x}/{y}.pbf` の要求に応じてWorker内で生成し、非表示時と地図破棄時にWorkerを終了する。
H3本体はWorker内で読み込む。ネットワークからグリッドを取得する必要はない。

## 解像度

ズーム0からH3解像度0で始まり、ズーム3・4・6・7・9・10・11・13・14・16・17・18・20・21・22で
解像度1〜15へ順に切り替える。定義元は `utils/mesh/h3-levels.ts`。
コードは中心点に表示し、重なるラベルは間引く。

## タイル生成

タイルの四隅・辺の中点・中心を含むセルから隣接セルをたどり、境界の外接矩形がタイルに重なるセルを取得する。
解像度0では全122セルを調べる。日付変更線をまたぐ辺は経度を連続化し、geojson-vtでタイルに切り出す。
H3固有の五角形も同じ経路で処理する。表示はWeb Mercatorタイルがカバーする緯度範囲となる。
探索には4096セルの上限を設け、不適切な解像度で広域の生成を要求された場合はエラーにする。

境界はLineStringとして渡すため、タイルの切断位置に偽の境界線は生じない。
セルの座標とIDは [h3-js](https://github.com/uber/h3-js) 4.4.0を使用する。
